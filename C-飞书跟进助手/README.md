# 小华 · 飞书跟进助手 P0 MVP

基于本目录 PRD、WhatsApp/丢单/节点样例及相邻工作台的卫华品牌色实现。前端和后端均已落地，可执行确认回填、风险分级和飞书真实导出。

当前交付是 **工作台操作 + 飞书真实写入的最小 MVP**；不等同于 PRD 中完整的飞书群机器人 P0。

## 打开与运行

- 本机地址：http://127.0.0.1:4183（飞书跟进助手独立端口）
- Node.js 22 或以上，运行服务不需要额外 npm 依赖。
- 当前会话已启动本地服务。关闭后重新运行：

```powershell
cd 'E:\卫华黑客松\C-飞书跟进助手'
npm start
```

首次启动按当天生成演示日期。客户、节点、草稿、月报、日志存于 `data/runtime/state.json`，重启保留；种子为虚构数据。服务每 30 秒扫描本地节点，关闭服务后停止扫描。

## 已实现

| 功能 | 当前能力 |
|---|---|
| 前端 | 总览、沟通摘要、节点预警、文字风险、成交丢单月报、飞书连接、运行评测，共 7 页；含窄屏布局和键盘焦点样式 |
| 沟通摘要 | 粘贴文本或前端读取 TXT/EML；中文/英文关键词抽取；诉求、顾虑、待办、数字保留原句与行号；未明确的相对日期不猜测 |
| 确认回填 | 草稿先预览，确认后追加客户跟进；同时具备绝对日期和负责人的待办创建节点；忽略、重复确认幂等 |
| 节点扫描 | 按 PRD 自然日规则；采购 ≤3、4–7、>7 天；投标逾期直接红；已完成/取消排除；缺日期标黄；下游生产影响提示 |
| 节点编辑 | 修改计划日期、供应商预计日期、完成状态后即时重算；关联自动风险同步更新或关闭 |
| 提醒队列 | 本地 30 秒扫描；同节点同等级 24h 抑制、升级立即生成新提醒；完成显示解除一次；没有自动发群 |
| 文字风险 | 关键词识别，排除普通会议延期；先生成草稿，提交人确认后入库，可选择黄/橙/红 |
| 丢单与月报 | 11 类规则归因；信息不足不猜、歧义标复核；月份过滤、成交/丢单/暂停统计、原因/区域条形图、固定 6 节报告、Markdown 下载 |
| 飞书 | 复用 lark-cli 用户身份，建立本 Demo 独立 Base 四张表；按本地 ID 创建或更新；写入后逐字段读回；生成真实飞书月报 |
| 上游 API | `/api/ingest` 接受本地轻量 Opportunity / QuoteResult 示例，外部 ID 幂等，缺负责人拒绝；未验证 A/B 真实接口契约 |
| 质量验证 | 31 个自动测试含 HTTP、DOM 交互、规则、存储与飞书读回处理；已有 14 条样例评测；9 项真实服务/飞书联调 |

## 请你现在体验

1. 打开 Demo →「沟通摘要」→「载入中英文样例」→「生成摘要」→ 核对诉求/顾虑/待办及原文行号 →「确认回填」。在总览看到跟进记录增加。
2. 「节点与预警」→ 编辑“主起升减速机到货”的供应商预计日期 → 保存。查看延迟天数和“可能影响主梁组焊”；改成已完成，查看风险解除。
3. 「风险登记」→ 载入风险样例 → 识别 → 确认登记。再试“下午的周会延期到四点”，应提示未发现项目风险。
4. 「成交与丢单」→ 选择当前月 → 生成月报。核对 15/27/3 和 35.7%，创建或打开飞书文档。
5. 「飞书连接」→ 检测连接 → 同步四表 → 打开 Demo Base，核对刚确认的跟进和风险。这个同步是手动的，不会双向读取飞书修改。
6. 「运行与评测」→ 运行样例评测，查看 14/14 和操作日志。

## 尚未实现 / 下一步

1. **优先接飞书原生交互**：独立应用配置、群绑定、@消息事件、卡片按钮回调/权限、30 秒变更轮询、工作日 8:30 群内推送。当前只完成本地提醒队列和显式同步。
2. **接入模型与评测**：当前没有大模型密钥，运行模式明确为“原文抽取 + 确定性规则”。摘要没有语义翻译、复杂意图理解，也没有达到 PRD 所需的召回率评测。丢单没有模型二级复核，界面暂不能修改分类标签或确认复核项。
3. **语音与真实业务数据**：没有 ASR、语音附件、Excel 导入、群历史自动读取、通讯录身份绑定、风险按人统计仪表盘、CRM/SAP 回写。
4. **生产化**：JSON 单进程存储、仅本机访问；没有多用户账号、后台常驻部署、外部审批角色鉴权、完整操作撤销、多人并发与完整 Acemode 评测集。飞书每表读回最多 200 行，超限明确报错；当前 85 行销售表在限制内。
5. **视觉手验**：电脑工具无法可靠确认 Windows 浏览器 URL，停止了浏览器 UI 操作；没有完成真实浏览器点击与截图验收。DOM 表单集成测试通过，但不保证字体、缩放和窄屏视觉表现。
