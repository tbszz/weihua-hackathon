# P1：重工业 AIGC 短视频 Skill

状态：已接入 Loomi 风格技能目录与 Magpie 可替换 provider；不作为 P0 自动剪辑链路的前提。未配置 `MAGPIE_BASE_URL` 时使用本地 mock，API key 对本机反代可为空。

## 职责

`industrial-aigc-video` 为卫华起重机场景生成用于短视频的设备演示、工业概念画面与场景化解释，再调用主 Agent 的自动剪辑能力进行精剪、配音、字幕、包装与 QC。可独立接收主题，也可接受自动剪辑发现的素材缺口。

## 输入与输出

输入：主题、产品型号、已核对的 Claim、设备参考图、目标画幅和时长、发布渠道、风格约束、可选实拍素材、模型与预算上限。

输出：`AigcVideoPlan`、生成片段 `MediaAsset[]`、每个片段的模型/提示词/参考资产/生成标识/审核状态、自动剪辑任务 ID、成片与 QC 报告。保持角色、主梁、支腿、钢丝绳与吊钩结构一致；无法验证设备结构时采用明显概念风格并标注 AI 生成示意。

## 主链路

1. 主 Agent 从需求判断实拍剪辑或 AIGC 创作，选择 `industrial-aigc-video`。
2. Skill 拆解短视频脚本与分镜；产品事实只来自 Claim，模型不补写额定吨位与工程参数。
3. 通过可替换的模型 Provider 生成片段；当前实现使用 `src/server/magpie.ts` 适配 Magpie 反代的 `/videos` 任务接口，不默认启动 ChatCut 离线补素材工作流。
4. 持久化生成任务 ID、预算消耗和资产来源，轮询已有任务，不因观察超时重新提交。结果先审核再进入素材库。
5. 调用主 Agent 的自动剪辑能力：`createStoryboard → selectShots → renderFilm → QC`。保留生成标识，可混合经授权的实拍镜头。
6. 交付 MP4、封面、字幕与来源清单，供用户人工发布短视频。公众号图文交给 D，不在此 Skill 内实现。

## 验收

同一产品至少完成一个 15–30 秒的概念短视频；生成片段能交给自动剪辑能力组合成片；可追溯模型任务与来源；失败/取消任务不重复扣费；每条生成画面有标识；事实参数通过与 P0 相同的校验；本 Skill 缺席或生成失败不影响 P0 实拍剪辑。
