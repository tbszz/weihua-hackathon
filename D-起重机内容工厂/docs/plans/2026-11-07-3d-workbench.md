# 3D 科普工作台实施计划

目标：在现有 React / Three.js 基础上实现有细节的门机装配体、GLB 读写、剖视、零件树、三视图和爆炸视频导出。用户已要求本轮全部实施，不再设置方案确认环节。

架构：`crane-model.js` 管理层级、几何、运动和资源释放；`viewer-runtime.js` 管理渲染、相机、拾取、剖切与多视口；`CraneWorkbench.jsx` 管理用户操作和导出任务。现有参数与服务端保留。

验收步骤：
1. 先建立模型测试：唯一部件 ID、有效三维边界、跨度变化、四层拆解、GLB 二进制往返。
2. 建立参数化 3800t 通用示意：双主梁及桁架、四支腿、端梁、轮组、双小车、小车架、电机、减速机、卷筒、绳系、滑轮和吊钩。
3. 用 Three.js 正交相机、轮廓线、环境光与软阴影重做大画布；零件树与拾取双向联动，支持聚焦/隔离/重置。
4. 实现剖切方向与位置，三视图用同一模型正交投影；导出同一画布 PNG。
5. 预生成真实 GLB 到 public/models，允许本地 GLB 导入；按节点名重建零件树，无层级模型明确提示。
6. MediaRecorder 录制画布 12 秒爆炸拆解为 WebM；支持取消，恢复原视图，停止轨道并回收 URL。
7. 运行几何/GLB 测试、构建与 API 检查；仅内置浏览器执行交互验收。浏览器无法连接时单独记录，不把编译当视觉通过。

边界：这是宣传示意模型。没有真实工程图，机构尺寸和内部细节不能宣称为官方结构；剖视为裁剪平面视图，不生成工程剖面封口。WebM 不包含配音。
