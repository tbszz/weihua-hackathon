# 卫华 · 海外招投标助手 MVP

本目录独立运行的前后端演示，Python FastAPI + SQLite + 原生网页。复用主项目的品牌色、Claim 原文证据、人工复核和对象命名约定；平台底座尚无可运行代码，因此通过本地适配器实现闭环。

## 启动

在本目录终端执行：

```powershell
python -m pip install -r requirements.txt
python -m uvicorn src.server.main:app --host 127.0.0.1 --port 8011
```

打开 http://127.0.0.1:8011 。接口文档 http://127.0.0.1:8011/docs 。

```powershell
python -m pytest -q
```

## 测试数据

- 公开招标样本及原始快照：`data/public_notices.json`、`data/sources/`。保留真实截止时间，历史公告不改成在招项目。
- 完整流程与制裁阻断两个夹具为模拟数据；公司证照为模拟台账，无真实证照文件。
- 公司资料、授权代表、材料包全部标注模拟。仅内部演示，红黄项不会自动变为齐全。
- 本地状态、复核记录、飞书去重映射和下载包在 `data/runtime/`，不进入版本控制。
- 搜索与抽取为规则实现。未配置大模型、不发送公司资料给云端模型；复杂资格、业绩金额和跨语言条款仍需人工核验。
- 背调真实名单尚未接入，显示 `unknown / 数据不足`；虚构制裁夹具仅测试一票否决，不能用于真实风控。

## 飞书

使用本机已经授权的 `lark-cli`，凭证留在 CLI，不写入网页或源代码。MVP 默认连接本次创建的专用测试表，点击“同步飞书”写入记录，重复同步按公告 ID 更新。首次成功同步会尝试向当前 CLI 登录用户发送一张测试卡片，不发送业务群。

切换自己的表可设置环境变量 `BID_FEISHU_BASE` 和 `BID_FEISHU_TABLE`。字段需要包含：商机名称、项目ID、国家、负责人、截止时间、复核状态、风险、数据类型、来源（均为文本）。运行 `lark-cli doctor` 检查连接。

## 人工演示路径

1. 搜索“中东 港口起重机 近3个月”，选择“完整流程样例”，认领商机。
2. 生成分析，核对原文片段及材料红黄绿，查看4份文书草稿。
3. 查看背调：真实数据未接入的项显示待核验；选择“制裁命中阻断”样例验证不可放行。
4. 输入复核人与意见，勾选缺口确认，通过后下载 ZIP。该包仅为内部模拟草稿。
5. 点击同步飞书，打开测试表核对；重复点击应更新原记录。
6. 勾选历史公告，检查公开原文来源；或导入自己的公开公告文本，截止时间需包含时区。
