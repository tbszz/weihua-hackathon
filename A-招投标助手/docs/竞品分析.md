# 作品 A 竞品分析：招投标助手

> 结论先行：市场并不缺“标讯订阅”“AI 写标书”“飞书流程表单”这类通用能力；作品 A 的差异化应当收敛为 **海外起重机垂直找标 + 卫华资料库匹配 + 报名材料包生成 + 规则化背调 + 飞书协同闭环**。不要把自己讲成“又一个 AI 标书生成器”。

## 1. 竞品格局

| 类型 | 代表产品 | 核心优势 | 主要边界 |
|---|---|---|---|
| 通用标讯/情报平台 | 千里马、剑鱼标讯、保标招标、知了标讯 | 数据源广、历史数据厚、覆盖全国公告，支持订阅、画像、竞对分析和 API/MCP | 以国内公共采购为主；不内置卫华资料库，也不负责海外起重机材料包 |
| AI 标书生产工具 | 喜鹊标书、招采猫、巧文书、智标AI、标创云 | 强在招标文件解析、评分点提取、目录生成、正文初稿、废标风险与查重 | 常见输入是已拿到的招标文件；对“标前找标、报名资格、授权/承诺文件、甲方背调”覆盖较弱 |
| 飞书生态方案 | 飞书多维表格、审批、云文档、豆包工作伙伴/Aily | 协作、审批、知识库、权限、任务和消息入口天然强；已有招投标智能体实践 | 通用平台不内置起重机词表、卫华材料库、海外源清洗规则和确定性背调规则 |
| 垂直智能体平台 | 智标领航、链企 Buddy | 智能体/专家团覆盖多岗位、多行业，支持知识库与私有化 | 偏国内投标与标书生产；行业知识与流程仍需企业自行配置 |
| 国际招标平台 | XAGENT、TendersWorld、Deepbloo、Bidovate、Tendersight | 覆盖多边银行、TED、190+ 国家或区域采购源，支持多语检索、合规矩阵、go/no-go、投标管理 | 面向通用行业与英语/区域规范；不理解卫华产品线、战区、授权链与公司材料库 |
| 数据/API 底座 | 知了开放平台、保标 API、Deepbloo API/MCP | 可把标讯数据接入自有 Agent、CRM、BI、MCP 工作流 | 数据层不解决材料包、审批流和公司内部证照有效期治理 |

## 2. 代表产品拆解

### 2.1 飞书：不是没有应用，而是缺垂直流水线

飞书官网明确把招投标管理作为审批、云文档、多维表格、知识库和项目管理的组合场景；官方社区已有“AI 招投标智能体”课程，覆盖招标文件解读、资质匹配、评分标准分析、竞对研究和投标决策。第三方知了标讯也支持推送到飞书。

- **优势**：组织内协作入口、权限、审批、任务、表格和知识库一体化；豆包工作伙伴/Aily 可接入企业知识与工具。
- **边界**：通用智能体缺少卫华的起重机多语词表、海外战区分发规则、证照有效期台账、授权书/承诺书模板和背调名单规则。
- **我们的定位**：复用飞书做分发、认领、复核和留痕；不重做协作平台。作品 A 提供飞书不具备的垂直 Pipeline。

### 2.2 千里马 / 剑鱼 / 保标 / 知了：数据与情报强

- **千里马**：标讯规模和历史数据大，支持多维筛选、智能订阅、竞对监控、行业分析、AI 标书和风控；喜鹊标书强调评分点、废标项与知识库。
- **剑鱼标讯**：强在实时监测、早期商机、采购单位/竞对画像、区域市场分析和结构化数据输出。
- **保标招标**：强调自然语言找商机、企业画像、竞对动向、API/MCP 和数据覆盖。
- **知了标讯**：三大能力分明——商机大师做每日精选与策略，招采猫做标书生成，开放平台把 3.1 亿级标讯数据接给企业 Agent。
- **共同优势**：数据、推荐、画像和开放接口是通用平台护城河。
- **共同边界**：主要服务国内公告；即便推送飞书，也仍需人工把公告转成卫华可执行的报名材料包。
- **我们的差异化**：只聚焦起重机/物料搬运海外标；输出 `TenderPackage` 而不是公告列表；用资料库把“能投”变成材料状态和缺口清单。

### 2.3 喜鹊 / 招采猫 / 巧文书 / 智标AI：标书生产强

- **共同能力**：上传招标文件后提取资格、评分、废标与响应要求，生成目录、正文、偏离表，并进行合规检查、查重和排版。
- **优势**：解决“写标慢”“漏响应”“废标风险”的高频痛点；知识库可复用企业资料。
- **边界**：核心价值在拿到招标文件之后；对海外多源找标、报名注册清单、小语种公告解析、多边银行合规和公司材料有效期治理不是主战场。
- **我们的差异化**：P0 不做大标书代写，而做投标前置链路：找标 → 解析资格 → 匹配资料 → 生成授权书/承诺书 → 背调 → 复核 → 交给作品 B 报价。

### 2.4 TendersWorld / Deepbloo / XAGENT：国际投标闭环强

- **TendersWorld**：发现、决策、起草、管理一体化；强在统一 180+ 国家检索、win probability、价格区间、合规矩阵、引用式回答和审计。
- **Deepbloo**：强在 190+ 国家、多语转英文、查询 Agent、招标文件秒级分析、go/no-go，并开放 API/MCP。
- **XAGENT**：宣传覆盖联合国、世行、亚开行等国际组织和 190+ 国家，提供标讯聚合、文件解析、标书生成、供应商匹配和策略分析。
- **共同优势**：国际源覆盖、跨语言检索、投标全生命周期和协作管理。
- **共同边界**：不懂卫华产品线与竞品；不维护卫华证照、授权主体、业绩边界和材料模板；难以直接输出符合内部审批要求的报名 zip 包。
- **我们的差异化**：国际平台的广度不可比，作品 A 改比 **行业深度与公司内闭环**：起重机语料和负向词、战区分配、卫华主体资料库、授权文件模板、确定性风险分、飞书和作品 B/C 的自动流转。

## 4. 差异化定位

### 4.1 一句话

**别人做“找到公告”或“写完标书”，我们做卫华海外投标前置流水线：把公告变成可认领、可复核、可直接交付报价的报名材料包。**

### 4.2 四个差异化主轴

1. **行业垂直**：内置 overhead crane、gantry crane、port crane、hoist 等多语词表与 crane hire 等负向词，避免通用平台把“吊车租赁”“塔吊施工”误推给业务员。
2. **公司资产化**：把证照、资质、业绩、人员、模板变成结构化资料库，输出已有/缺失/过期/需人工状态，而不是只给 AI 摘要。
3. **风险可解释**：甲方/供应商背调用确定性规则表计分，模型只做摘要；每条结论都有来源，数据不足就降级人工复核，不让模型拍“能不能投”。
4. **组织闭环**：飞书负责分发、认领、提醒和审批；材料包输出作品 B 报价、商机输出作品 C 跟进，形成跨作品业务流。

### 4.3 竞争话术

- 对比飞书：飞书是协同底座，不是卫华海外起重机投标专家；我们把飞书表格和消息变成自动流水线。
- 对比千里马/知了：它们解决“公告很多”，我们解决“卫华能不能报、缺什么材料、甲方有什么风险”。
- 对比 AI 标书：它们从拿到文件后开始写，我们在拿到文件前后完成找标、资格匹配、报名材料和背调。
- 对比 TendersWorld/Deepbloo：国际平台赢在广度，我们赢在起重机行业深度、公司资料库和内部流程闭环。

## 5. 对 PRD 的取舍建议

1. P0 继续坚持“材料包 + 背调 + 飞书闭环”，不扩大到完整技术标/商务标生成，避免与成熟标书工具正面竞争。
2. 突出三个演示爆点：材料状态红黄绿、授权书/承诺书自动填充、规则化背调一票否决。
3. 海外找标不承诺“全网覆盖”，承诺“聚焦优先市场的可解释召回”；数据源覆盖率在界面明示。
4. 保留人工复核作为产品能力而非兜底话术：未经 `core.review` 不能导出，正好区别于“一键生成即提交”的工具。
5. 若后续商业化，可与知了/保标/Deepbloo 这类 API/MCP 数据源合作，把作品 A 定位成行业应用层，而不是自建全网采集平台。
