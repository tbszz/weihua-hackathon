# P0 MVP 实施设计

用户已授权直接实现前后端并手动测试。沿现有 PRD，关键闭环为：搜索 → 认领 → 公告要求与原文证据 → 资料状态 → 中英文文书草稿 → 背调缺口 → 人工复核 → 导出及飞书同步。

实现放在作品 A 内，避免影响其他并行作品。底座当前仅有设计文档，本地 SQLite/CLI/导出器是临时适配层，保留未来迁移边界。采用 Python FastAPI 同源服务而非另建 Node 构建链，利用本机已安装文档库；前端采用原生网页，减少启动步骤。

品牌令牌沿用主目录 `weihua-ai-workbench/colors_and_type.css`：卫华红 #D7000F，正文 #1F2329，背景 #F5F6F7，白色面板，细分隔线。侧栏负责导航，左侧标讯列表，右侧从证据到复核的工作面板。用材料状态和原文对照体现行业任务，不依赖官方 IP 形象。

真实公告保留真实发布日期和截止日；历史样本独立展示。两个模拟夹具确保完整材料流程和制裁阻断可重复测试。解析仅抽取正文实际出现的片段；不认识的要求交人工。资料有效期以投标截止日判断。没有实时背调名单时风险为未知，禁止伪装低风险。

复核确认通过只解锁内部模拟包，真实材料缺口和待签章持续保留。确定性测试覆盖门禁、原文证据、日期边界、制裁阻断、输入验证和导出包。浏览器按人工路径验证页面交互；飞书按写入、读回、重复同步去重检查。
