**规格的常见写法**：`起重量(主钩/副钩)t - 跨度 m - 工作级别`。例如 `3800t-107m` 表示 3800 吨、跨度 107 米。

- **起重量**：额定能吊起的最大重量，单位 t。
- **跨度**：两条轨道中心线之间的距离，单位 m。
- **起升高度**：吊钩最高位置到地面或轨面的距离。注意它和**整机高度**不是一回事，例如 3800t 的起升高度 130 m，整机高度 166.5 m。
- **工作级别 A1–A8**：按使用频繁程度和载荷状态分级，数字越大越繁重。A3 属于轻级，A5 属于中级（普通车间常见），A6、A7 属于重级（冶金、码头），A8 为特重级。
- **主梁结构**：单主梁 / 双主梁；箱形梁 / 桁架梁 / 偏轨梁。
- **小车**：在主梁上横向移动、带起升机构的部分。双小车表示两台小车可以联合抬吊。
- **大车**：沿轨道纵向行走的整机。
- **刚腿 / 柔腿**：门机两侧的支腿。一侧刚性连接，一侧铰接（柔腿），用来释放热胀冷缩和偏斜应力。
- **抬吊**：多个吊钩同时吊一个构件。单钩、双钩、三钩抬吊都是官方新闻里常见的说法。
- **翻身**：在空中把构件翻转 90° 或 180°，造船分段常用。
- **重载试验**：通常按 1.25 倍额定载荷进行，例如 1200 t 的设备用 1500 t 试验；**静载试验**和**动载试验**也常见（1.1 倍是常见的动载试验倍数）。

## 2. 新中式起重机

卫华在 2021 年推出的新一代轻量化、模块化、智能化起重机系列。和传统产品相比更矮、更轻、更省电。官网的几种说法：
- 各项指标降低 15%–30%；
- 高度降低约 30%，自重降低约 25%，能耗降低约 20%；
- 噪音降低约 20 dB。

## 3. 报价、技术协议用语

| 术语 | 含义 |
|---|---|
| 标配 | 标准配置。产品目录里默认就有的部件、参数和品牌，无需额外设计 |
| 选配 | 目录里有，但需要客户选择、另外加价的配置，比如进口电机、变频调速 |
| 非标 | 非标准件或非标准设计。超出标准配置的特殊尺寸、工况、材质、认证，需要单独设计和核价 |
| 模糊 | 选题方案自定义的标签：需求写得不清楚、需要和客户澄清的条款 |
| 不满足 | 选题方案自定义的标签：现有产品做不到的条款 |
| 可偏离 | 选题方案自定义的标签：可以在投标偏离表里申报偏离的条款 |
| 技术协议 | 合同附件，写明参数、配置、品牌、验收标准、质保等 |
| 技术规格书 / 招标文件技术部分 | 客户给出的技术要求，报价时要逐条应答 |
| 偏离表（技术 / 商务） | 投标文件中逐条声明“满足 / 偏离”的表格 |
| 工况 | 使用环境和条件：温度、粉尘、防爆区域、室内外、风载等 |
| 配套件 | 外购的核心部件：电机、减速机、制动器、变频器、钢丝绳、轴承等 |
| 品牌清单 | 客户指定或认可的配套件品牌，例如 ABB、SEW、施耐德、正泰 |
| 最高限价 / 拦标价 | 招标方设定的报价上限 |
| 中标候选人 / 中标结果公示 | 招标流程中的公示阶段 |
| 指导价 | 蒲瑞产品页显示的价格（统一是 1.00 万），是占位价，不是真实报价 |

## 4. 部件（蒲瑞产品线）

- **减速机**：降低转速、增大扭矩。蒲瑞有 H、F、K、QY、HK、ZSC、ZQ、QJ、BT、ZJ 等系列。
- **车轮组**：大车和小车的行走轮，直径 Φ160–1000 mm。材质有 ZG340-640（铸钢）、ZG50SiMn、65Mn、42CrMo（锻钢）等。
- **卷筒**：缠绕钢丝绳，直径 Φ300–3000 mm。
- **吊钩组 / 滑轮组 / 联轴器 / 吊具 / 抓斗**。
- 轴承品牌选项：哈轴、瓦轴、洛轴、SKF、FAG、NSK。
