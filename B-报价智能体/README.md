# 报价智能体 P0 Demo

这是 B 作品的最小可运行闭环：载入/上传文字协议 → 脱敏 → 规则分析 → 五类清单与原文高亮 → 风险偏离表 → 人工改判 → 知识条目 → 组长入库 → 导出 QuoteResult / CSV / SOP。

## 启动

```powershell
npm start
```

打开终端打印出的地址，默认是 `http://127.0.0.1:4173`。如果 4173 被占用，服务会自动尝试后续端口；本次环境中使用 `http://127.0.0.1:4174`。

## 建议手测路径

1. 点击“载入演示协议”，确认右上角任务号和本地模式出现。
2. 查看左侧原文：联系人、手机号和合同金额已脱敏；工程参数仍保留。
3. 点击右侧“减速机”或左侧对应高亮，确认详情里有协议原文、标配库、规则 ID 和加价标准依据。
4. 在详情里把判断改成“可偏离”，填写改判理由和报价思路，提交。
5. 切到“知识沉淀”，点击“组长通过，入库”，确认状态变成“已入库”。
6. 切到“风险偏离表”，确认延期罚则、质保期和验收条款出现，然后导出 CSV。
7. 点击“下载 QuoteResult”验证结构化结果，点击“飞书消息预览”验证可复制的消息 JSON。
8. 用“上传文本协议”换一份 `.txt` 或 `.md`，验证同一分析闭环。

## 左侧导航

- **协议审阅**：回到原文和五类清单。
- **任务列表**：展示所有已分析的本地任务，可重新打开历史协议，也可以新建演示任务。
- **知识审核**：汇总各任务的改判条目，可通过、填写理由退回、查看改判审计。侧边数字表示待审核数。
- **评测面板**：实际运行 11 条固定规则回归，展示逐条预期、实际结果和运行时间，可重新运行。它不是对真实协议准确率的评估。

三个辅助入口使用右侧抽屉展示，点击右上角 × 或按 Esc 返回协议审阅。窄屏时左侧保留图标入口。

任务及审核结果保存在 `data/runtime/tasks.json`，仅用于本机单人演示；刷新页面或重启后会恢复最近的任务。当前组长角色仍为演示，未接入真实身份权限。之前未持久化的内存任务无法补回，需要重新载入。

## 当前 P0 范围

已完成：本地规则引擎、入口脱敏、五类标签、原文高亮、双证据链、风险偏离表、人工改判、知识条目审核、QuoteResult/CSV/SOP 导出、飞书消息预览。

未完成：PDF/DOCX 解析、扫描件 OCR、真实卫华标配/加价/历史报价库、真实模型调用、真实飞书发送、最终报价计算、售前软件和 SAP 接口、形象/数字人。

当前演示数据均为模拟数据，价格和规则阈值不能直接作为生产报价依据。
