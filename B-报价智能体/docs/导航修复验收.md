# 左侧导航修复验收

问题：左侧“任务列表 / 知识审核 / 评测面板”原本只有按钮外观，无导航事件，也没有对应内容。

修复：

- 将四个导航入口接入显式目标，协议审阅回到主工作区，三个辅助入口打开对应抽屉。
- 任务列表读取真实历史任务并可重新打开，改判、导出、知识审核显式绑定 task_id，避免审核串任务。
- 任务和审核结果以脱敏后的 JSON 保存在本地，刷新页面及重启服务可恢复。
- 知识审核支持通过、带理由退回和查看真实改判审计；待审数字取实际队列数量。
- 评测面板每次调用规则引擎运行 11 条固定模拟回归，显示预期值和实际值，无写死的通过数。
- 静态资源禁止缓存，窄屏保留全部导航图标。

验证：

1. `npm test`：11 项通过，包括 DOM 点击、打开旧任务、跨任务审核、数据持久化与固定回归执行。
2. 真实浏览器：任务列表空状态 → 新建演示任务 → 减速机改判为可偏离 → 知识审核通过 → 待审数由 1 变为 0 → 查看审计。
3. 真实浏览器：评测面板显示 11/11，通过“重新运行评测”更新时间。
4. 刷新浏览器后恢复相同 task_id、人工改判和知识条目，再从任务列表成功打开协议。

截图：`demo/screenshots/navigation-evaluation.jpg`。

边界：规则和数据仍为模拟；组长审核是本地演示角色，飞书消息发送、真实角色权限及知识在下一份协议中检索未包含在本次导航修复中。
