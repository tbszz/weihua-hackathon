# 预测准确率升级设计

## 目标

在现有 5 条物料/单位序列和 7/14 天滚动回测框架上，提高点预测准确率，同时避免为了降低 WAPE 而系统性低估需求、放大缺货风险。

## 证据与问题

现有四个基础模型都是“整段历史压成一个水平值”的模型。样例数据中，工字钢 7002000342 的需求集中在周五、周六，周日几乎没有需求；7005002850 也有明显的星期差异。对这类间歇需求，单纯日均值会把尖峰摊平，单纯中位数又容易预测为 0。WAPE 单指标会奖励“预测 0”的模型，因此不能单独作为库存场景的模型选择标准。

## 方案

1. 增加 `dow_mean`：按历史星期几计算需求画像，支持窗口和收缩系数；预测日期保留星期几信息。
2. 增加 `median`：作为稳健点预测候选，减少极端领用对点预测的影响，但不允许仅因 WAPE 低就自动选中。
3. 记录有符号误差，并设置覆盖率门槛。模型预测总量低于验证期实际总量 65% 时，不允许仅凭 WAPE 被选中；这会排除间歇需求下的全零中位数预测。
4. 对通过覆盖率门槛的模型计算低估惩罚，并只在 WAPE 接近时作为次级排序：

   `selection_score = pooled_WAPE + 0.25 × |signed_error_sum| / actual_sum`

   这个分数仍以 WAPE 为主，同时惩罚持续高估或低估。系数 2.0 作为 MVP 可配置参数。
5. 在同一物料/单位、同一预测窗口和同一历史窗口上比较所有候选模型，先选择最低 WAPE，再用 `selection_score` 和 MAE 处理接近结果；报告同时保留 WAPE、MAE、偏差、覆盖率和选择分数。
6. 库存风险模拟继续使用需求均值和交期 P90 计算安全库存，点预测模型只负责未来日需求路径，避免稳健点预测直接削弱安全库存缓冲。

## 预期结果

- 工字钢优先利用星期几画像，降低集中领用造成的误差。
- 需求稀疏的物料可以使用中位数或间歇模型，但低估偏差会被显式展示。
- 结果可解释、可回测；如果新模型没有真实改善，自动保留原模型。

## 验收

- 新模型有单元测试：日期对齐、单位隔离、无历史星期样本回退、非负输出。
- 选择逻辑有测试：候选模型的低估偏差会影响排名，不能用全零预测绕过。
- 全量回测通过，输出新旧模型的 WAPE、MAE、偏差、选择分数和相对基线改进。
- 所有现有测试保持通过。
